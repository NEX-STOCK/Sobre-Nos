## 📋 Sobre o Projeto

O **NEXSTOCK** é um aplicativo mobile desenvolvido para descomplicar o controle de inventário de ponta a ponta. Seja para pequenos negócios ou grandes operações, o app oferece uma interface intuitiva e ferramentas poderosas para garantir que você nunca perca o controle do fluxo de mercadorias. O sistema integra desde o cadastro ágil com código de barras até a gestão de logística e notas fiscais.

---

## 🌟 Funcionalidades

O projeto foi dividido em 11 módulos principais para cobrir todas as necessidades de uma operação de estoque:

*   🔐 **Autenticação:** Sistema de Login e Cadastro seguro para controle de acesso (Tela 1).
*   📊 **Dashboard Inteligente:** Resumo do estoque, alertas automáticos, produtos próximos da validade e necessidades de reposição (Tela 2).
*   📦 **Gestão de Estoque e Produtos:** Visão geral de todos os produtos, quantidades e situação atual. Cadastro detalhado com código, lote, validade e preço (Telas 3, 5 e 6).
*   📱 **Leitor de Código de Barras Integrado:** Utilize a câmera do dispositivo para localizar ou cadastrar produtos de forma instantânea (Tela 4).
*   ⚠️ **Lotes e Validades:** Controle rigoroso com visualização de lotes e acompanhamento proativo de produtos próximos do vencimento (Tela 7).
*   🔄 **Controle de Reposição:** Monitoramento de produtos abaixo do mínimo, classificados por nível de urgência, com acesso rápido ao contato dos fornecedores/repositores (Tela 8).
*   🛒 **Pedidos e Orçamentos Rápidos:** Crie e gerencie pedidos ou orçamentos com facilidade, agilizando o relacionamento com clientes (Tela 9).
*   🧾 **Gestão de Notas Fiscais:** Facilite a burocracia fotografando, anexando e consultando notas fiscais diretamente pelo app (Tela 10).
*   🚚 **Logística e Rastreamento:** Acompanhamento de pedidos, controlando o fluxo de entradas, saídas e movimentações internas (Tela 11).
